# 二次开发文档一

> 第一次二次开发改动

## 改动

本次改动的目标只有一个：

- 单实例下，报告和推送使用不同的筛选文件

改动后的行为：

- 报告继续走全局筛选配置
- 推送可以单独指定筛选文件
- 不配置推送专用文件时，行为和原来一致

新增配置：

```yaml
notification:
  frequency_file: ""
  interests_file: ""
```

配置规则：

- 全局 `filter.method=keyword` 时，推送只看 `notification.frequency_file`
- 全局 `filter.method=ai` 时，推送只看 `notification.interests_file`
- 这两个字段只影响推送，不影响报告
- 推送专用文件中的词或兴趣描述，不要求同时存在于全局主配置中

没有改动的部分：

- `notification.enabled`
- 调度里的 `push / once.push`
- 报告生成逻辑
- 采集逻辑
- 通知渠道配置

也就是说：

- 该不该推送，还是原来的逻辑
- 什么时候推送，还是原来的逻辑
- 报告看什么，还是原来的逻辑
- 这次只改“推送内容按哪份文件筛”

## 使用方式

先看你全局现在用的是哪种模式：

- `filter.method: "keyword"`
- 或 `filter.method: "ai"`

先明确一个规则：

- 推送专用文件是单独读取、单独计算的
- 你写在 `push_focus.txt` 里的词，不需要再同步写进全局 `frequency_words.txt`
- 你写在推送专用 AI 兴趣文件里的内容，也不需要再同步写进全局 `ai_interests.txt`

也就是说：

- 报告看全局主配置
- 推送看 `push_focus.txt`
- 两边内容可以不重合

### 方式一：关键词模式

适用条件：

```yaml
filter:
  method: "keyword"
```

配置步骤：

1. 在 [config/config.yaml](/Users/changhuanli/explore/TrendRadar/config/config.yaml) 的 `notification` 段加上：

```yaml
notification:
  enabled: true
  frequency_file: "push_focus.txt"
```

2. 新建文件：

- [config/custom/keyword/push_focus.txt](/Users/changhuanli/explore/TrendRadar/config/custom/keyword/push_focus.txt)

3. 文件内容按关键词文件格式写。最简单可以先这样写：

```txt
[WORD_GROUPS]

[AI]
AI
人工智能
大模型
OpenAI
ChatGPT
DeepSeek

[黄金]
黄金
金价
贵金属
现货黄金
COMEX黄金
```

结果：

- 报告继续使用全局主词库
- 推送只使用 `push_focus.txt`
- `push_focus.txt` 里的词不需要同时出现在全局主词库里

### 方式二：AI 模式

适用条件：

```yaml
filter:
  method: "ai"
```

配置步骤：

1. 在 [config/config.yaml](/Users/changhuanli/explore/TrendRadar/config/config.yaml) 的 `notification` 段加上：

```yaml
notification:
  enabled: true
  interests_file: "push_focus.txt"
```

2. 新建文件：

- [config/custom/ai/push_focus.txt](/Users/changhuanli/explore/TrendRadar/config/custom/ai/push_focus.txt)

3. 文件内容按 AI 兴趣描述文件格式写。最简单可以先这样写：

```txt
下面是我要关注的内容：

1. AI 与大模型：关注 AI、人工智能、大模型、OpenAI、ChatGPT、DeepSeek、Agent、算力、推理成本、模型发布与行业应用。
2. 黄金与贵金属：关注黄金、金价、贵金属、现货黄金、COMEX 黄金、避险资产、央行购金、国际金价波动。

- 不要标题党
- 不要营销软文
```

结果：

- 报告继续使用全局主兴趣文件
- 推送只使用 `push_focus.txt`
- 推送专用兴趣描述不需要同时写进全局主兴趣文件

## 你需要新建哪些文件

如果你走关键词模式，新建：

- [config/custom/keyword/push_focus.txt](/Users/changhuanli/explore/TrendRadar/config/custom/keyword/push_focus.txt)

如果你走 AI 模式，新建：

- [config/custom/ai/push_focus.txt](/Users/changhuanli/explore/TrendRadar/config/custom/ai/push_focus.txt)

这两个文件代码不会自动帮你创建内容，你需要自己写进去。

仓库里这两个目录已经存在：

- [config/custom/keyword](/Users/changhuanli/explore/TrendRadar/config/custom/keyword)
- [config/custom/ai](/Users/changhuanli/explore/TrendRadar/config/custom/ai)

所以你只需要新建对应的 `push_focus.txt` 即可。

## 生效方式

如果你改的是下面这些文件：

- `config/config.yaml`
- `config/custom/keyword/push_focus.txt`
- `config/custom/ai/push_focus.txt`

Docker 下一次定时执行时就会读取到。

如果你改的是 `docker/.env`，则需要重启容器。

## 限制

当前只支持“同一种筛选模式下分开文件”，不支持跨模式强制切换。

例如支持：

- 报告 `keyword`，推送 `keyword`
- 报告 `ai`，推送 `ai`

暂不支持：

- 报告 `keyword`，推送强制 `ai`
- 报告 `ai`，推送强制 `keyword`
